# Coffee Level Detection Bot
In this project I have developed an machine vision algorithm that takes an image of a Moccamaster coffee maker and detect the current amount of coffee in the coffee pot. This information can them be used as for real-time monitoring of the coffee maker or data analysis of the coffee consumption. The algorithm has been integrated to Raspberry Pi microcomputer and it has been in active use during 2024.

## Development
The current implemention is not very state of the art solution and I would like to work on this project more when I have time. I have a lot of ideas currently on how to improve both the image processing part and the classification.

## Usage
`main.py` will start running the Telegram bot and creates a thread for updating the coffee level values.
